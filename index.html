Hank's Tank

hankstank.com is a live prediction site for MLB, NFL and college football that I build and run on my own. I wrote all of it: data ingestion, features, models, evaluation, the API and the site. Every game prediction, power ranking and season projection on it comes out of my pipeline.

  • Evaluation decides what ships. A candidate model is backtested walk-forward against the current one on the same games, with confidence intervals, then runs as a live shadow before it can replace anything. In football a margin ridge model replaced XGBoost this way (NFL 2017–24 log loss 0.634 vs 0.646). Anyone can rerun that comparison in seconds with make demo.
  • Honest numbers. The MLB model picked 54.0% of 1,984 games correctly before first pitch in 2026, against a 52.8% home-team win rate. Baseball games are close to coin flips. An experiment log records every result, including the ideas that failed.
  • Pipeline operations. I moved 13 production jobs from Cloud Functions to my own server in three staged cutovers. Each job went off, then dry run, then live, with only one system writing at a time. The cloud version stays deployed as a fallback.
  • Control and monitoring. A control table lets me pause, pin or hide any model on the live site without a deploy. Checks for stale data, missing predictions and mismatched model files alert my phone. Each check exists because something once failed while reporting success.
