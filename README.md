# Portfolio

Source for [elijahcraig45.github.io/portfolio](https://elijahcraig45.github.io/portfolio/), a one-page summary of my
work: Hank's Tank, the homelab and lab behind it, ml-edge, experience and education.

Plain HTML and CSS: no build step and no JavaScript. GitHub Pages serves `main` as is.

- `index.html`: the page
- `assets/css/styles.css`: the styles, with a dark mode that follows the system setting
- `assets/images/`: the headshot and a screenshot of hankstank.com
- `assets/icons/icon-HC.png`: the favicon

To preview it, open `index.html` in a browser.
